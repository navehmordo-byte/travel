# 🥾 שבילים בארץ

אפליקציית ווב למטיילים שמציגה מסלולי טיול בכל הארץ – רגליים ואופניים, עם כלב או בלי כלב.

## מה יש באפליקציה
- **חלונית חיפוש** – חיפוש חופשי לפי שם מסלול, אזור או מילה מהתיאור.
- **סינון לפי סוג** – 🚶 רגלי / 🚴 אופניים / הכל.
- **סינון לפי כלבים** – 🐕 עם כלב / 🚫 בלי כלב / לא משנה.
- **סינון לפי אזור ורמת קושי**.
- **מפה אינטראקטיבית** – כל מסלול מסומן בצבע לפי סוגו (ירוק = רגלי, כתום = אופניים, סגול = שניהם).
- **הכוונה (ניווט)** – כפתור "נווט ב-Waze" (לפי שם המקום, `navName`) ו-Google Maps (לפי קואורדינטות מדויקות) לנקודת ההתחלה של כל מסלול.
- **קרוב אליי** – מיון המסלולים לפי המרחק מהמיקום הנוכחי. אפשר גם לבחור עיר מהרשימה או ללחוץ על נקודה במפה.
  - איתור מיקום עובד רק בכתובת מאובטחת (https, למשל GitHub Pages) או ב-localhost – לא בפתיחת הקובץ ישירות.
  - דפדפנים שבתוך אפליקציות (Outlook, Gmail, וואטסאפ) חוסמים לפעמים מיקום – במקרה כזה פתחו את הקישור ב-Chrome או Safari.

## הרצה
אין צורך בהתקנה. פותחים את `index.html` בדפדפן, או מריצים שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש ל- http://localhost:8000
```

אפשר גם לפרסם בחינם דרך **GitHub Pages** (Settings → Pages → Deploy from branch).

## הוספת מסלול
מוסיפים רשומה לקובץ `data/trails.js`:

```js
{ id: 77, name: "שם המסלול", navName: "שם לחיפוש ב-Waze", region: "אזור", lat: 32.0, lng: 35.0,
  type: ["walk", "bike"], dogs: true, dogNote: "כלבים ברצועה",
  difficulty: "קל", lengthKm: 5, durationH: 2, circular: true, water: false,
  description: "תיאור קצר" }
```

## ⚠️ הערה חשובה
המידע באפליקציה הוא לצורך התרשמות בלבד. ככלל, בשמורות טבע אסור להכניס כלבים, וביערות קק"ל ובפארקים מותר בדרך כלל עם רצועה. לפני יציאה לטיול, בדקו את ההנחיות העדכניות מול רשות הטבע והגנים וקק"ל.
